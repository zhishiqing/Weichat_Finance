📡 后端 API 端点 (v2.1)

GET /api/health 健康检查
GET /api/v1/merchant 列出所有启用商户
GET /api/v1/merchant/{mchId} 查询单个商户配置
POST /api/v1/payment/jsapi/create 创建 JSAPI 订单（返回 prepay_id）
GET /api/v1/payment/order/{outTradeNo} 主动查单
POST /api/v1/payment/order/{outTradeNo}/close 关闭未支付订单
POST /api/v1/payment/native/create 创建 Native 订单（返回 code_url）
POST /api/v1/payment/refund/create 申请退款（幂等）
GET /api/v1/payment/refund/{outRefundNo} 查退款进度
POST /api/notify/v3/pay/success 微信支付回调（验签+解密）
POST /api/notify/v3/refund/success 微信退款回调（验签+解密）

🏗️ 后端架构说明

统一响应：所有 Controller 返回 R<T> = { code, message, data }

CORS：开发期放行 http://localhost:*，生产应由网关处理

MDC traceId：前端请求头 X-Trace-Id → 后端 MDC → 日志串联

支付模式：环境变量 WX_PAY_MODE = MOCK（默认）/ REAL

双保险查单：v1.5 主动轮询（3s/次）+ v1.2 兜底（30min 扫描）
